# 《NVIDIA Jetson AI硬件开发实战》配套代码

本仓库收录《NVIDIA Jetson AI硬件开发实战》系列图书的配套代码，按书、按章节整理。

## 目录

- [`入门篇/`](入门篇/) — 《NVIDIA Jetson AI硬件开发实战：入门篇》全书代码，共 251 个代码块（ch02～ch08，ch01 无代码），章节索引见 [`入门篇/README.md`](入门篇/README.md)
- `进阶篇/` — 待图书上市后发布

## 文件命名

文件名格式为 `p页码_序号_标识.扩展名`，页码为**印刷页码**，便于对照原书。每个文件头部注释标明出处章节、页码与书中上下文。

## 提取与修复说明

- 代码自书中逐块识别、逐字重建：排版折断的长行已重新拼接，排版软件产生的字距伪空格与弯引号已修复，跨页代码清单已合并为一个文件。
- 代码内容（含注释、缩进风格）忠实于原书；书中以省略号呈现的配置节选按原样保留；少数代码块为终端输出或目录树，以 `.txt` 保存并在索引中标注类型。
